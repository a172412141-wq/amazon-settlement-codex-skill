# QA Checklist

Before delivering a completed workbook:

1. Confirm each PDF produced exactly one workbook row.
2. Confirm report month equals the month in the PDF filename or date range.
3. Confirm income, expenses, tax, and transfer values match the PDF summary table.
4. Confirm the audit CSV includes raw signed PDF values and workbook-written values.
5. Confirm expense and transfer sign conventions match the workbook formulas.
6. Confirm currency code and exchange rate source date.
7. Confirm RMB formulas refer to the same row and do not contain stale row numbers.
8. Confirm only expected cells changed; no format changes were made.
9. Confirm output workbook opens without warnings.
